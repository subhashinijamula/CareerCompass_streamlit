# Dataset data dictionary

Each row is one synthetic demonstration profile. Ratings are integers from 1 (beginner/low) to 5 (advanced/high), except `cgpa` (4–10) and `education_level` (1=diploma, 2=bachelor's, 3=master's). `career` is the illustrative target label.

The dataset contains 1,440 synthetic rows (180 for each of eight career categories). It includes education, academic score, technical skills, strengths and interest ratings. Profiles are generated by sampling around manually specified illustrative role profiles with noise. This dataset is for software demonstration only, not empirical career prediction.
